# Ro & Co Blommor

A three-page website for **Ro & Co Blommor**, a florist in Stockholm. Visitors can browse the bouquet categories, read customer reviews and the shop's story, and send an order request or message through the forms. The site is built with plain **HTML and CSS only** (no JavaScript).

The design was made in Figma before being built.

## Live site

The website is deployed with GitHub Pages: [https://....github.io/.../](https://....github.io/.../)

## Pages

| Page | What's on it |
|------|--------------|
| **Home** | Intro, "Our Services" with an *Order a bouquet* button, customer reviews, and "Our Story" |
| **Products** | Bouquet categories (Seasonal, Wedding, Get well soon), price range options, and an order request form |
| **Contact** | Opening hours, contact details, and a form to send a note to the shop |

All pages share the same navigation bar at the top and a footer with the shop's phone number, address, and social media links.

## Features

- Soft green and cream colour palette
- The **Order a bouquet** button on the Home page links directly to the Products page
- Hover effects on the product pictures and the price range buttons
- Order form with address, delivery date and time, phone number, and an optional note
- Contact form with an optional note

## Built with

- HTML5

- Figma (design)

## Running the project locally

No installation or build step is needed.

1. Clone the repository:
   ```bash
   git clone https://github.com/..../....git
   ```
2. Open the project folder.
3. Open `index.html` in your browser (or use the **Live Server** extension in VS Code).

## Project structure

```

├── home.css          # Home page styles

├── contact.css       # Contact page styles

```
