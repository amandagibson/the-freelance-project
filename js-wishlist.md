Products Page

Select a Bouquet Type: When a user clicks on one of the three bouquet photos (Seasonal, Wedding, or Get well soon), JavaScript adds an active border to that image and saves which style was picked. 

Single Price Selection: Clicking one price button (like 250 kr- 450 kr) highlights it and automatically un-highlights the other two so only one budget is active at a time. 
    
Live Letter Counter: As someone types inside the "Add Note (optional)" box, JavaScript counts the characters and displays text underneath (for example: 42 / 200 characters).  
     
Date Picker Safety Check: JavaScript checks today's date so customers cannot pick a delivery date in the past.
     
 Order Confirmation Pop-up: When the user clicks "Send the request", JavaScript checks that the address and phone fields are not empty, pops up a "Thank you! Your order has been placed" message, and clears the form.
 
 
 
 
    Home Page
    
 "Order a Bouquet" Shortcut: Clicking the "order a bouquet" button smoothly takes the user straight to the Products page (products.html). 
    
    
  Customer Review Slider: Add left and right arrow buttons next to the reviews so JavaScript swaps between different customer review cards instead of showing them all at once. 
  
  Dynamic Star Rating: Allow visitors to click on empty stars to leave their own 1 to 5 star rating. 
  
  
  
  Contact Page
  
  Live "Open Now / Closed" Indicator: JavaScript checks the real day and time on the visitor's computer and shows a green "Open Now" or red "Closed Now" tag right next to the opening hours.  
  
 Click-to-Copy Contact Info: When someone clicks the phone number or email address, JavaScript automatically copies it to their clipboard and shows a quick "Copied!" text bubble.
 
 Message Sent Alert: When the visitor types a message into the note box and presses "Send the request", JavaScript displays a confirmation note saying "Message sent! We will reply within 24 hours". 
 
 
  Site Navigation
  
  Mobile Menu: On phone screens, hide the navigation links behind a menu icon that uses JavaScript to open and close when tapped. 
  
  Active Page Highlight: JavaScript checks which page file is currently open in the browser and underlines the correct menu link (Home, Products, or Contact) automatically.
